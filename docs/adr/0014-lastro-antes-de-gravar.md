# 0014 · Conferir o lastro dos números antes de gravar

Antes de gravar uma resposta, o agente confere que cada número apresentado aparece no resultado da consulta que a produziu. A mensagem só é entregue se passar pela verificação, para tornar os números rastreáveis aos dados consultados.

Descartadas: gravar a resposta sem conferência; confiar somente na instrução ao modelo para citar números corretos.
Custo aceito: respostas que não passam pela conferência são barradas, e a comparação pode exigir tratamento cuidadoso de formatos numéricos.
